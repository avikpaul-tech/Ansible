# Control Node: Installation & Environment Setup

## Step 1: Install Python 3.8 via Software Collections (SCL)
Run as root to enable SCL and install the modern Python runtime in parallel:

```Bash
yum install -y oracle-softwarecollection-release-el7
yum install -y rh-python38 rh-python38-python-pip rh-python38-python-virtualenv
```
**Verification:** Run /opt/rh/rh-python38/root/usr/bin/python3 --version to confirm Python 3.8.x is installed.

## Step 2: Initialize Virtual Environment for ansible User
Log in as the ansible user and isolate the Ansible installation:

```Bash
su - ansible
```
# Create virtual environment from the SCL Python 3.8 binary
```bash
/opt/rh/rh-python38/root/usr/bin/python3 -m venv ~/ansible-venv
```
# Activate the virtual environment
```bash
source ~/ansible-venv/bin/activate
```
## Step 3: Upgrade Packaging Tools & Pin Dependencies
Upgrade pip and install a compatible cryptography library to avoid deprecation notices on Python 3.8:

```Bash
pip install --upgrade pip setuptools wheel
```

## Step 4: Install Ansible
Install the full Ansible suite inside the isolated virtual environment:

```Bash
pip install ansible
```
**Verification:** Run ansible --version. Confirm the binary location points to /home/ansible/ansible-venv/bin/ansible and the runtime is Python 3.8.


## Step 5: Configure Automatic Shell Activation
Ensure the virtual environment loads automatically whenever the ansible user logs in:

```Bash
echo "source ~/ansible-venv/bin/activate" >> ~/.bashrc
```

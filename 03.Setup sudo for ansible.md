## Perform the below steps in each managed nodes:

### 1. Login as root user. Navigate to /etc/sudoers.d/
```bash
# cd /etc/sudoers.d/
```

### 2. Create a file 'ansible' and add the following entry as shown below. Save the file
```bash
# vi ansible
ansible ALL=(root,oracle,grid) NOPASSWD: ALL
```

### 3. Login as ansible user and test the sudo connection. 
```bash
sudo su -
sudo su - oracle
sudo su - grid
```

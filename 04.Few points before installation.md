## Python Version Requirements:
### Control Node: 
- Modern Ansible releases require Python 3.8+ to support the orchestration engine, modern connection plugins, and updated security libraries.
- Base OS Limitation (Oracle Linux 7.9): The default OS Python is Python 2.7.5 (required by yum), while standard repository packages only provide Python 3.6.8.
- Replacing system Python breaks core OS tools.

**Solution:** 
On the Control Node, Python 3.8 will be installed in parallel via Oracle Software Collections (SCL) (/opt/rh/rh-python38/), leaving the OS defaults untouched. Ansible will be isolated inside a Python Virtual Environment (venv) under a dedicated ansible service account.

### Managed Node: 
Managed nodes only execute small, ephemeral Python scripts dispatched over SSH. Installing base python3 (Python 3.6.8) on target nodes satisfies remote execution requirements without introducing external repositories or modifying system packages on database servers.

### 1. Create user ansible in the control node and all the managed nodes
```bash
# useradd ansible
# passwd ansible
```

### 3. Copy the public key to all the managed nodes using ansible user
```bash
[ansible@anscn ~]$ ssh-copy-id ansible@192.168.29.122
[ansible@anscn ~]$ ssh-copy-id ansible@192.168.29.123
```

### 4. Test the passwordless ssh setup
It should not ask any password to login. Test the connection for all managed nodes.
```bash
[ansible@anscn ~]$ ssh ansible@192.168.29.122
Last login: Sun Nov  1 13:05:38 2026
```

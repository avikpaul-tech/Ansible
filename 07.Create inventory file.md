## Steps to create inventory file

1. Login as ansible user in the control node
2. Create the inventory file
```bash
cat << 'EOF' > ~/ansible-oracle/inventory/hosts.ini
# Individual hosts
[db_standalone]
192.168.29.122
192.168.29.123

# Example RAC cluster structure (add when scaling out)
[db_rac]
# racnode01.example.com cluster_name=prod-rac
# racnode02.example.com cluster_name=prod-rac

# Parent group encompassing all database nodes
[oracle_servers:children]
db_standalone
db_rac
EOF
```
4. Verification: Run ansible-inventory --graph. It should output an ASCII tree showing the oracle_servers parent group containing db_standalone with 192.168.29.122
